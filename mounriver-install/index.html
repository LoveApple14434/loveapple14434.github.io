在Arch Linux上使用MounRiver Studio开发沁恒单片机

Created2026-11-09|Updated2026-11-09|寄术
|Word Count:540|Reading Time:1mins|Post Views:

为了开发一些跟NFC相关的小玩意，了解到沁恒微出了一款带全速USB2.0，蓝牙和NFC的单片机CH585，于是火速（并没有）上淘宝购买了一块评估板来玩玩。49r包邮能买到这么一块开发板，个人认为性价比还是可以的。

简单看了一下沁恒微官网上提供的资料，开发推荐用的是一个叫MounRiver Studio的神秘IDE套件，网站看起来很现代但是略显AI感，疑似是一个用VSCode改出来的换皮IDE。好消息是，虽然Windows只提供整个IDE，但是Linux提供单独的工具链压缩包，而这显然（吗？）更加优雅。

遂打开Arch Linux，在AUR上搜索了一下，果然有如下包可用：

于是直接使用yay进行下载。这里出现了一个小问题：mounriverstudio-toolchain-bin的PKGBUILD提供了一个空的源文件做dummy，实际下载是在prepare()函数里，但是这个空的dummy不知为何给我返回429error不许我下载。替代的解决办法是用yay -G mounriverstudio-toolchain-bin先下载PKGBUILD文件，然后手动注释掉source和sha256sums的两行，然后执行makepkg -si即可安装了。

下载完发现被骗了，下载的还是一整套IDE，这很不优雅，让水煮鱼十分恼火。于是水煮鱼卸载了mounriverstudio-toolchain-bin，然后做了如下工作：

这样就非常优雅地安装了两个工具链，分别用于编译和调试。前者提供了位于/usr/bin/的openocd-wch-riscv和openocd-wch-arm两个命令行工具，直接用就可以；而后者提供的命令会通过/etc/profile被加载，可能需要重新登录bash启用。
